## 2. 数据流（配置/内容自动更新）

```mermaid
sequenceDiagram
    participant CIMS as CIMS 后端

```

## 3. 命令流（面板主路径：management HTTP，CIMS 原生）

> **已源码核实**：CIMS `management` 端口经 `app/api/management/account_router.py` 以
> `prefix="/account/{account_id}/client"` 原生挂载客户端控制接口，面板直接调用，
> **无需自建 HTTP→gRPC 命令代理**。

```mermaid
sequenceDiagram
    participant Console as 电教委员面板
    participant Mgmt as CIMS management
    participant CI as CIMS gRPC :27044
    participant Client as ClassIsland
    Console->>Mgmt: POST /user/auth → token
    Console->>Mgmt: POST /account/{acct}/client/{uid}/command/restart|update-data|send-notification
    Mgmt->>CI: 服务端单向推送命令
    CI->>Client: 下发命令
    Mgmt-->>Console: {status,message}
    Note over Mgmt,Client: 单向推送不依赖 bidi 下游回包 ⇒ 不受 grpcio 1.78 bidi bug 影响，MVP 即用
```

### 3.1 备用路径：bidi 实时流（当前不可用）

```mermaid
sequenceDiagram
    participant CIMS as CIMS gRPC
    participant Client as ClassIsland
    CIMS->>Client: ListenCommand 推送 (bidi)
    Client-->>CIMS: Pong / 执行结果
    Note over CIMS,Client: grpcio 1.78 真实 socket 有 bidi 边界（评估报告 §2.10）；in-process 24/24 全过。MVP 不依赖此路径
```

### 3.2 OS 级动作（锁屏 / 截图 / 远程屏）—— CIMS 无原生接口

```mermaid
sequenceDiagram
    participant Console as 电教委员面板
    participant Mgmt as CIMS management
    participant P as ClassIsland 插件
    participant A as 本地代理 127.0.0.1
    participant EXT as 扩展网关
    Console->>Mgmt: send-notification（MessageContent 内嵌 stelarith_task + 签名令牌）
    Mgmt->>P: 通知下发
    P->>A: POST /task（本地回环）
    A->>A: HMAC / Ed25519 验签 + ±60s 防重放
    A->>A: 执行 OS 动作 / 按需启动 VNC
    A->>EXT: 回报 VNC 会话 {ip,port,token}
    Console->>EXT: 轮询 /vnc-session?uid=
    Console->>Console: 拼 noVNC 地址内嵌远程桌面
```

## 5. 自动隐藏 / 自动更新 映射

| 能力 | 实现层 | 触发 |
|---|---|---|
| 自动隐藏浮窗 | ClassIsland 自动化 | 上课/投影/考试时段 → 切换视图/隐藏 |
| 客户端自动更新 | 内网更新源 | 更新器定时检查 → 升级 |
| 配置自动更新 | CIMS Manifest | 客户端定时拉取 → 刷新 |
| 批量运维 | CIMS 命令 | 管理端批量下发 RestartApp/更新 |
