## 它是什么

星璃·无限音乐画布是一款**本地音乐播放器**，不依赖任何云端服务。你的文件留在你的硬盘上，离线也能听。

它"会思考"的地方在于：用算法和小模型做智能策展——自动整理曲库、按场景排歌单、理解你当下的听歌节奏。所有推理都在设备本地完成，**听歌记录不上传**。

> [!NOTE]
> 核心理念是「可停留的空间」。播放器不该只是工具，而该是一个能安静陪伴你的地方。

## 为什么做它

在线音乐平台的问题是：你并不拥有那些歌。下架、换版权、账号异常，收藏夹就可能少一半。而本地播放器的痛点是另一面——文件是自己的，但整理它们太累：命名混乱、元数据残缺、格式五花八门。

星璃想补的是后一半：**让"拥有一堆本地文件"这件事变得好用**。不拼曲库资源，拼的是体验——打开就知道听什么，看着舒服，听着沉浸。

## 技术栈

| 选型 | 角色 | 为什么是它 |
|------|------|-----------|
| **Flutter + Dart** | UI 框架 | 单一代码库跨 Windows / macOS / Linux / Android / iOS，视觉完全自定义 |
| **Riverpod** | 状态管理 | 编译期安全、可测试，应对播放队列 / 循环 / 均衡器等交叉状态 |
| **media_kit** | 音频引擎 | 基于 libmpv，啃得下 FLAC / DSD / APE 等冷门无损格式 |
| **SQFlite** | 本地存储 | SQLite 封装，持久化曲库、歌单与收藏 |
| **isolate** | 并发扫描 | 几万首歌的扫描与指纹计算不阻塞 UI |
| **LiteRT / MediaPipe** | 端侧推理 | 小模型跑本地歌单策展，数据不出设备 |

> [!TIP]
> 音频引擎选 media_kit 而非 just_audio，是因为本地播放器没有"格式选择权"——用户硬盘里什么都有。冷门无损放不出来是最差体验，多花的那点包体值得。

## 明确的边界

| 不做 | 原因 |
|------|------|
| 社交评论 | 本地工具，不做社区 |
| 云端推荐 | 不收集用户数据，隐私是前提而非选项 |
| Hi-Fi 玄学 | 以听感与体验为准，不炒器材 |
| 在线曲库 | 不做版权资源的搬运与聚合 |

这几条边界不是"还没做"，是**决定不做**。它们定义了产品是什么，也定义了它不是什么。
