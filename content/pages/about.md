# 星璃内容中枢

这里不是又一个博客平台，而是 **「星璃 / Stelarith」** 这个独立创作品牌的内容中枢：一个本地优先、隐私友好的个人互联网空间，也是星璃产品与开源组件的统一门户。

## 核心：星璃品牌

「星璃」是一组围绕「可停留的空间」这个理念打造的产品：

- **星璃·无限音乐画布** —— 会思考的本地音乐播放器，算法与小模型驱动，听歌记录不上传。
- **星璃·体素大厅** —— 沉浸式的体素世界与白噪音空间。
- **星璃平台** —— 串联上述产品的账号、同步与生态底座。
- **星璃知识库** —— 沉淀设计、工程与产品思考的 Wiki。

## 支撑：生态组件

让星璃跑起来的开源组件与工具：

- **DeepSeek Harness（dsh）** —— 把大模型变成能干活的工具链。
- **中转服务器（net-relay）** —— 联机「一起听」与体素联机的星型房主。
- **集控广播（ClassIsland Broadcast）** —— 校园场景的信息播报与集控。
- **Fonscape** —— 生态中的另一块拼图。

## 这里有什么

- **工程笔记（博客）**：记录真实落地中的架构取舍与踩坑。
- **教程**：大模型 API 与 DeepSeek Harness 的入门指南。
- **项目**：上面这些产品的专页。
- **文档 / 页面**：随时扩充的资料。
