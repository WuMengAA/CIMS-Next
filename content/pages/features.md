# 功能介绍

欢迎使用 **星璃内容中枢**。本站既是一个面向全校的内容与协作空间，也承载了校园信息播报与教室设备的集控能力。下面按模块说明你能做什么、谁会用、入口在哪。

## 模块总览

| 模块 | 入口 | 主要使用者 | 能做什么 |
| --- | --- | --- | --- |
| 内容社区 | `/posts` `/projects` `/docs` `/pages` | 全体师生 | 阅读博客、项目专页、教程文档；教师可发布内容 |
| 论坛 | `/forum` | 全体师生 | 发起话题、回复讨论、求助答疑 |
| 音乐空间 | `/voicehub` | 全体师生 | 本地音乐策展与沉浸式聆听 |
| 公告 | `/announcements` | 全体师生 | 查看学校/班级通知，置顶紧急事项 |
| 反馈 | `/feedback` | 全体师生 | 提交建议、报障，跟踪处理进度 |
| 校园集控 | `/admin/console` | 管理员 / 电教委员 / 班主任 | 锁定屏幕、发送广播、远程操控教室设备 |
| 附件库 | `/admin/media` | 后台管理员 | 上传资料、生成直链、按类型检索与删除 |
| 账号与绑定 | `/account` | 全体师生 | 管理个人信息、绑定班级/年级 |
| 搜索 | `/search` | 全体师生 | 全站检索文章、文档、项目与页面 |

## 按角色快速上手

- **我是教师** → 看 [教师使用简介](/pages/guide-teachers)，了解如何发布内容、发布公告、使用集控面板。
- **我是学生** → 看 [学生使用简介](/pages/guide-students)，了解如何绑定班级、接收集控、下载附件。

## 需要权限的功能

集控面板与附件库属于管理类功能：

- **集控面板**要求登录账号具备相应权限，且进入前需完成**班级绑定**；未绑定的账号会被引导先补全班级/年级信息。
- **附件库**仅在后台可见，用于资料的后台上传统一管理。

> 如果你只需要浏览与参与讨论，无需任何特殊权限——直接在学校网络内打开本站即可。
