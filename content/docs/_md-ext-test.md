本站的 Markdown 渲染管线在标准语法之外，自己实现了一批增强语法（零第三方依赖，直接挂在 markdown-it 的 ruler 上）。写文章时可以直接用，这篇既是速查表，也是实时的渲染自检——**下面每一段的效果都是真实渲染出来的**。

## 上标与下标

语法：`^上标^`、`~下标~`。注意下标用的是单个 `~`，不会和原生删除线 `~~文字~~` 冲突。

水的化学式是 H~2~O，勾股定理是 a^2^ + b^2^ = c^2^。

## 高亮

语法：`==需要高亮的文字==`

这里有一段 ==需要高亮的文字==，其余保持正常。

## 提示块（Callout）

语法：`> [!类型] 标题`，标题可省略（省略时回退为中文默认标签）。

> [!TIP] 这是带标题的提示
> 提示块内部的 **加粗** 与 `行内代码` 应当正常渲染，
> 并且列表也要正常：
> - 第一项
> - 第二项

> [!WARNING]
> 这是没有写标题的警告块，标题应回退为默认中文标签。

> [!DANGER] 危险
> 这里是危险提示。

支持的类型与默认中文标题：

| 类型 | 默认标题 | 类型 | 默认标题 |
|------|----------|------|----------|
| `tip` | 提示 | `note` | 注释 |
| `info` | 信息 | `success` | 成功 |
| `warning` | 警告 | `danger` | 危险 |
| `important` | 重要 | `caution` | 注意 |
| `question` | 疑问 | `example` | 示例 |
| `quote` | 引用 | `abstract` | 摘要 |
| `summary` | 总结 | `todo` | 待办 |

## 代码块与行内代码

围栏代码块标注语言名即可获得 highlight.js 高亮。

```js
const a = 1; // x^2^ 与 ==mark== 在代码里必须保持原样
```

行内 `x^2^` 与 `==mark==` 同样保持原样——**增强语法不会误伤代码**，这是刻意设计的。

## 数学公式（KaTeX）

行内公式：`$E = mc^2$` → $E = mc^2$

独立公式：

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$

## ⚠️ 引用标记的正确写法

文末若有「## 参考来源」编号列表，正文里用**普通 `[1]`** 与之对应。

> [!WARNING]
> **不要写成 `^[1]^`。** 这个写法会被脚注插件当成脚注引用，但因为没有脚注定义，页面底部会渲染出一个**内容为空的脚注区**（只显示数字和回车箭头），点击引用还会跳到空条目。
>
> 正确：`...的能力 [1]`　错误：`...的能力 ^[1]^`

## 写作约定

| 约定 | 说明 |
|------|------|
| 内容即时生效 | 改完 md 存盘刷新即可，**无需重新构建** |
| 引用标记 | 用 `[1]`，不用 `^[1]^` |
| 代码块 | 务必标注语言名，否则无高亮 |
| 表格 | 行之间**不要夹空行**，否则可能被拆散 |
| 链接 | `[文字](URL)`，不要把 URL 也写进文字里造成嵌套 |
