# 星集控 · 统一界面美术规范（纯文字）

> 生效：2026-10-06 ｜ 适用：官网 stelarith（SvelteKit）与 Qt 管理端（viewer-qt）所有新页面/组件。
> 规则：**不造第二套风格**。新界面必须复用既有 token/组件，改样式前先看这里。

---

## 一、技术栈与组件源（唯一真源）

| 端 | 组件库 | 图标 | 样式系统 |
|----|--------|------|---------|
| 官网 | `$lib/components/ui/*`（shadcn-svelte 风格） | `@lucide/svelte` | Tailwind + CSS 变量（`--primary` 等） |
| Qt 管理端 | QML 自绘（`qml/Main.qml` 的 `th.*` 主题对象） | — | 黑白主题：`th.win/panel/card/body/fg/fg3/cream/inv/stroke/sepline` |

**铁律**：官网页面一律从 `$lib/components/ui/` 取 Button/Badge/Input/Card 等；**禁止**内联 `<style>` 造新色值、**禁止**写死 `#xxx` 十六进制（特殊强调色除外，见 §四）。

---

## 二、色彩（Token 语义，不直接用色值）

### 官网（Tailwind + CSS 变量）
| Token | 用途 | 说明 |
|-------|------|------|
| `bg-background` | 页面底色 | 浅色 #fff / 深色 #09090b（跟随系统） |
| `bg-card` / `bg-muted` | 卡片 / 灰底区块 | 卡片是主要信息容器 |
| `border-border`（常用 `border-border/60`） | 描边 | 卡片、输入框统一 1px |
| `text-foreground` | 主文字 | 标题/正文 |
| `text-muted-foreground` | 次级文字 | 说明、时间、元信息 |
| `text-primary` / `bg-primary` | 强调 | 链接、激活态、主按钮（品牌色，勿改） |
| `text-emerald-500` | 成功/安全 | 校验通过、已复制、绿色状态 |
| `text-amber-500` | 警告/未决 | 待处理、不可下载、黄色状态 |
| `text-destructive` | 危险 | 删除、拒绝、红色状态 |

**规则**：
- 状态色**只用** emerald（成功）/ amber（警告）/ destructive（危险）三个语义，不引入新的彩色。
- 深浅色自适应：用 token，不写死黑白。特殊强调（品牌渐变、警示图标底色）可用 `bg-primary/10` `border-primary/60` 这类**带透明度的组合**，不新增色值。

### Qt 管理端（`th.*` 黑白主题）
| Token | 值 | 用途 |
|-------|-----|------|
| `th.win` | 深底 #141414 | 窗口/导航底色 |
| `th.panel` | #1e1e1e | 卡片面板 |
| `th.body` | #0d0d0d | 页面底色 |
| `th.fg` | #fff | 主文字 |
| `th.fg3` | #888 | 次级文字 |
| `th.cream` | #f5f0e1 | 强调（选中/激活） |
| `th.inv` | 反转 | 选中态底色（cream 上的深字） |
| `th.stroke` | 描边 | 输入框/分隔线 |
| `th.sepline` | #141414 | 导航分隔线 |

**规则**：管理端**只用黑/白/灰 + cream 强调**，不引入蓝色/彩色（历史教训：蓝底 Button 与黑白主题冲突，用户否决过）。

## 三、布局与组件规格

| 组件 | 规格 | 示例 |
|------|------|------|
| 卡片 | `rounded-xl border border-border/60 bg-card p-6` | 所有信息容器 |
| 主按钮 | `Button`（primary 默认） | 下载、提交、保存 |
| 次按钮 | `Button variant="secondary"/"ghost"/"outline"` | 取消、返回、次要动作 |
| 徽标 | `Badge variant="secondary"/"outline"` | 版本号、分类 |
| 分类胶囊 | `rounded-full border px-3 py-1 text-xs` | 搜索页/下载页分类 tab |
| 输入框 | `Input` / `rounded-lg border bg-card` | 搜索、表单 |
| 列表项 | `divide-y divide-border/40 py-3` | 结果列表、审核列表 |
| 强调面板 | `rounded-lg border bg-muted/30 p-3` | 说明框、提示框 |

**圆角体系**：卡片 `rounded-xl`（12px），控件 `rounded-md`（6px）/ `rounded-lg`（8px），胶囊 `rounded-full`。
**间距体系**：卡片内 `p-6`（24px），组件间 gap 按 Tailwind 档位（`gap-2`=8px / `gap-3`=12px / `gap-4`=16px）。
**字号**：页面标题 `font-heading text-xl font-semibold`，正文 `text-sm`，元信息 `text-xs text-muted-foreground`，等宽（版本/哈希）`font-mono text-[10px] text-muted-foreground`。

## 四、特殊强调（允许的例外色）

| 场景 | 色 | 用法 |
|------|-----|------|
| 品牌渐变（hero 区） | 已有 CSS 变量，不改 | 仅限首页 hero |
| 金色吸附线（Qt 时间轴拖拽） | `#ffd33d` | 拖拽吸附预览专用 |
| 深色提示条（Qt 集控页 toast） | `#e0a03a` | 操作结果提示 |
| 通知严重度（Qt 集控页） | remind 绿 / inform 黄 / urgent 红（映射到状态语义） | 按钮选中态 |

除此之外**不新增**例外色。新增前先问「能不能用现有 token 表达」。

## 五、交互规范

1. **点击反馈**：所有可点元素（Button/胶囊/MouseArea）必须有过渡（`transition-colors`）或状态变化（`hover:border-primary/50`、QML `hovered` 高亮）。
2. **空态**：列表为空时显示居中说明文字（`text-sm text-muted-foreground py-8 text-center`），不显示空白。
3. **加载/失败**：如实显示状态（「暂时取不到版本信息」「网络错误」），**不用旧数据假装**。
4. **复制可校验值**：sha256 等给复制按钮，复制后反馈「已复制」（Check 图标）。
5. **表单校验**：必填、格式（HH:mm 等）在提交前校验并给提示，不静默失败。
6. **禁用的就置灰**：无权限/未发布的按钮 `disabled` + `variant="secondary"`，不假装可用。

---

## 六、可访问性

- 可点击的 `<div>` 必须给键盘事件或改用 `<button type="button">`/`<a>`。
- 表单 label 必须关联控件（`label for` 或 aria-label）。
- 图标按钮给 `title` 或 aria-label。
- 颜色对比：正文用 `text-foreground`（对比度达标），次级用 `text-muted-foreground`（≥4.5:1）。
